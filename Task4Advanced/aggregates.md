# Агрегаты

## Домен: медобслуживание

Контекст: запись и визит
- сущности: пациент, визит, слот
- объекты-значения: интервал времени, кабинет, ФИО, дата рождения, контакты, пол
- агрегат Пациент, ключ patientId
    - граница: идентификатор и анкета пациента в клинике, не клиент банка
    - инвариант: один patientId на человека в этом контексте
    - событие: Зарегистрирован пациент
- агрегат Слот, ключ slotId
    - граница: кабинет + интервал + врач, статус свободен/занят
    - инвариант: один слот — не больше одной активной записи
    - свои события не публикует, статус меняет по «Создана запись на слот», «Запись отменена», «Пациент не явился»
- агрегат Визит, ключ visitId
    - граница: ссылка на slotId, patientId, staffId врача, статус, счёт
    - инвариант: визит без слота и пациента не существует
    - события: Создана запись на слот, Пациент прибыл, Пациент не явился, Приём начат, Завершён визит, Запись отменена, Выставлен счёт за визит


Контекст: постановка диагноза
- сущности: диагноз
- объекты-значения: код диагноза, формулировка
- агрегат Диагноз, ключ diagnosisId
    - граница: заключение врача по визиту (visitId и staffId снаружи)
    - инвариант: диагноз ставит врач, рекомендация ИИ диагнозом не является
    - событие: Поставлен диагноз

Контекст: история болезни
- сущности: история болезни, запись в истории
- объекты-значения: дата записи, тип записи, детали записи
- агрегат ИсторияБолезни, ключ medicalRecordId
    - граница: клинические записи одного пациента (patientId снаружи)
    - инвариант: запись без типа, даты и деталей не принимаем
    - событие: Обновлена история болезни, Выписано назначение

## Домен: финтех

Контекст: счёт
- сущности: счёт, клиент банка
- объекты-значения: валюта
- агрегат Счёт, ключ accountId
    - граница: владелец и остаток; остаток — состояние корня, не VO
    - инвариант: остаток меняется только пополнением или списанием
    - события: Открыт счёт, Счёт пополнен, Со счёта списано

Контекст: платёж
- сущности: платёж
- объекты-значения: сумма, валюта, назначение
- агрегат Платёж, ключ paymentId
    - граница: одно списание или зачисление, ссылка accountId, invoiceId если оплата визита
    - инвариант: сумма > 0, назначение указано
    - событие: Проведён платёж

Контекст: кредитный договор
- сущности: кредитный договор, решение по заявке
- объекты-значения: ставка, срок, условия ставки
- агрегат КредитныйДоговор, ключ contractId
    - граница: заявка, решение, условия и статус договора, ссылка на клиента банка
    - инвариант: договор без клиента банка не создаём, без решения об одобрении договор не активен
    - события: Создан кредитный договор, Кредит одобрен, Кредит отклонён, Изменены условия ставки

## Домен: ИИ определения диагноза

Контекст: рекомендация ИИ диагноза
- сущности: рекомендация, гипотеза
- объекты-значения: вероятность
- агрегат Рекомендация, ключ recommendationId
    - граница: запрос врача и ответ модели
    - инвариант: это совет, не диагноз
    - события: Запрошена рекомендация ИИ, Выдана рекомендация ИИ

## Домен: фармакология

Контекст: номенклатура и поставки
- сущности: позиция номенклатуры, поставка
- объекты-значения: количество, партия
- агрегат Номенклатура, ключ skuId
    - граница: позиция каталога
    - инвариант: sku уникален
    - событие: Добавлена позиция номенклатуры
- агрегат Поставка, ключ supplyId
    - граница: приход партии, ссылка skuId
    - инвариант: поставка без skuId не принимаем
    - событие: Получена поставка

## Домен: работа с мед техникой

Контекст: показания устройства
- сущности: устройство
- объекты-значения: метрика, значение, время съёма
- агрегат Устройство, ключ deviceId
    - граница: идентификатор аппарата, тип, кабинет; не весь архив показаний
    - инвариант: неизвестный deviceId показание не принимаем
    - события: Добавлено устройство, Получены показания устройства

## Домен: внутренние операции

Контекст: сотрудник
- сущности: сотрудник
- объекты-значения: должность, специальность, ссылка на клинику
- агрегат Сотрудник, ключ staffId
    - граница: кадровая карточка
    - инвариант: сотрудник привязан к одной оргединице
    - события: Добавлен сотрудник, Обновлены данные сотрудника, Сотрудник уволен

Контекст: учет товарно-материальных ценностей
- сущности: позиция ТМЦ
- объекты-значения: единица
- агрегат ПозицияТМЦ, ключ itemId
    - граница: тип позиции на складе, остаток — состояние корня
    - инвариант: остаток не уходит ниже нуля без списания; новый тип заводим без поступления
    - события: Добавлен тип ТМЦ, Изменён остаток ТМЦ

Контекст: внутренний учёт
- сущности: документ проводки, строка дебета, строка кредита
- объекты-значения: сумма, статья
- агрегат Проводка, ключ entryId
    - граница: документ с дебетом и кредитом
    - инвариант: сумма дебета равна сумме кредита
    - событие: Проведена внутренняя проводка

## Домен: аналитика

Контекст: витрины и портал
- Нет своих событий и агрегатов

## Домен: авторизация

Контекст: учётные записи и права
- сущности: учётная запись
- объекты-значения: роль, право доступа
- агрегат УчётнаяЗапись, ключ userId
    - граница: логин и набор ролей
    - инвариант: без роли прав нет
    - события: Создана учётная запись, Изменены права
